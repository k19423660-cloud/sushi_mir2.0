# Sushi Mir — інструкція запуску

## Що є в проєкті
- Адаптивний темний сайт Sushi Mir.
- Каталог, категорії, кошик та форма оформлення замовлення.
- Поля: ім'я, телефон, Telegram (необов'язково), отримання «з собою / у закладі», коментар.
- Окрема адмінпанель `/admin.html` або `/admin` для додавання, редагування, завантаження фото та видалення товарів.
- Замовлення надходять у Telegram.
- Товари зберігаються в Netlify Blobs, а не лише в браузері.

## ВАЖЛИВО ПРО БЕЗПЕКУ
Адмінпанель наразі без пароля, як було замовлено. Це означає, що будь-хто, хто дізнається адресу `/admin`, може змінити або видалити меню. Не публікуйте посилання на адмінку. Для реального магазину рекомендується ввімкнути пароль або Netlify Identity/Access Control.
Токен Telegram не зберігається в коді сайту. Не вставляйте його в `app.js`, `admin.js` або HTML.

## Безкоштовне розгортання на Netlify
1. Розпакуйте ZIP.
2. Відкрийте Netlify та створіть сайт через імпорт Git-репозиторію або Netlify CLI. **Netlify Drop для цього проєкту не підходить**, бо він завантажує статичні файли, а цьому сайту потрібні Netlify Functions та залежність `@netlify/blobs`.
3. Найпростіше: завантажте папку в GitHub, а на Netlify натисніть **Add new project → Import an existing project**, виберіть репозиторій.
4. Build command можна залишити порожнім; Publish directory — `.`. Netlify візьме налаштування з `netlify.toml`.
5. Після першого деплою відкрийте **Project configuration → Environment variables** і додайте:
   - `TELEGRAM_BOT_TOKEN` = новий токен від @BotFather
   - `TELEGRAM_CHAT_ID` = ваш Telegram chat ID
   Застосуйте зміни й зробіть новий deploy.

## Підключення Telegram
1. У Telegram відкрийте свого бота та натисніть **Start** або надішліть `/start`.
2. Отримайте свій chat ID: після `/start` відкрийте в браузері `https://api.telegram.org/botВАШ_НОВИЙ_ТОКЕН/getUpdates`. У відповіді знайдіть `message` → `chat` → `id`. Не публікуйте цю адресу та відповідь.
3. Додайте токен і chat ID у Netlify Environment variables, як описано вище.
4. Зробіть новий deploy і оформіть тестове замовлення.

## Адмінпанель
Відкрийте `https://ВАШ-САЙТ.netlify.app/admin` або `/admin.html`.
Фото — до 2 МБ за раз. Товари та фото зберігаються в Netlify Blobs.

## Примітки
- Netlify має безкоштовний рівень, але квоти й умови можуть змінюватися. Перевіряйте поточні ліміти в акаунті Netlify.
- Фото прикладу на головній сторінці завантажується з Unsplash; для власних товарів завантажуйте фото через адмінпанель.
- Якщо бот не надсилає замовлення, перевірте, чи натиснули Start у боті, чи правильні `TELEGRAM_BOT_TOKEN` та `TELEGRAM_CHAT_ID`, і чи був зроблений новий deploy після додавання змінних.
